My Projects

The following projects highlight my experience in cybersecurity, cloud technologies, databases, web development, research, and technical problem solving.

CRM API Security Risk Assessment - Informatica Industry Capstone

Worked with Informatica and cybersecurity expert Claudiu Popa as part of a six-member industry capstone team examining security and privacy risks introduced by CRM extensions, integrations, and third-party services.

I served as Team Lead and contributed to risk evaluation methods, vendor assessment processes, data-flow analysis, security recommendations, and a structured framework for assessing CRM extension risk.

AI Fitness Glasses Security Policy

Collaborated with a team to develop a security policy and risk assessment for hypothetical AI-powered fitness and health-tracking glasses.

I contributed to the security and privacy analysis of risks involving biometric data, wireless connections, cloud services, device software, and AI systems using the ISO 27005 risk management approach.

BooksInc Database Web Application

Developed the website functionality for a book and movie rental application created with a project partner.

My work focused on the Flask-based application features, including user interaction, browsing, renting, returning, and membership functionality, while my partner focused primarily on the MySQL database backend.

Campus Service Robot Feasibility Study

Worked with a partner to study student attitudes toward introducing service robots at Ontario Tech University.

I contributed to the research and analysis of student feedback involving privacy, safety, preferred robot tasks, operational limits, and realistic campus use cases.

Security Information and Event Management (SIEM)

Collaborated with a team on a cybersecurity research project examining SIEM systems and their role in organizational security.

I contributed to the research and analysis of concepts such as log management, threat detection, incident response, security monitoring, and implementation challenges.

E-commerce Trust System for Fraudulent Returns

Collaborated with a team to design a trust-based system for evaluating e-commerce return claims while reducing fraudulent activity without unfairly penalizing legitimate customers.

I contributed to the trust model design, scoring logic, and analysis of factors such as return rate, dispute frequency, verification status, transaction history, and behavioural consistency.

Ontario Tech Trips Cloud Transition with Terraform

Developed a cloud transition proposal for Ontario Tech Trips using Terraform and Infrastructure as Code to improve scalability, automation, disaster recovery, and infrastructure management.

My work focused on explaining Terraform's role in automated resource provisioning, version-controlled infrastructure, multi-cloud support, and safer deployment workflows.
